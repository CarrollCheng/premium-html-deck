# 🛠️ Premium HTML Deck Gen-Agent (premium-html-deck)

A powerful AI Agent Skill designed to transform raw notes, markdown outlines, and documents into executive-ready, premium 16:9 HTML presentation slide decks. Fully responsive, self-contained, and optimized for projection.

一个强大的 AI Agent 技能提示词，旨在将粗糙的笔记、Markdown 大纲和文档，直接转化为符合高管汇报标准的 16:9 高级 HTML 演示幻灯片。完全自包含、响应式，并针对投屏演示进行了极致优化。

---

## ✨ Features / 核心特性

- **📽️ Projector-Optimized (投影优化):** Fixed 16:9 viewport with large typography and high contrast. No accidental page scrolling. (固定的 16:9 视口、大号字体与高对比度，防止页面意外滚动。)
- **📦 100% Self-Contained (自包含):** Inline CSS & JS, zero external CDN dependencies. Works completely offline. (内联 CSS 与 JS，零外部 CDN 依赖，完全支持离线运行。)
- **⌨️ Seamless Navigation (流畅导航):** Supports Next/Prev onscreen buttons, arrow keys, and Spacebar. (支持屏幕导航按钮、键盘方向键和空格键控制。)
- **🖨️ Print to PDF (一键导出 PDF):** Built-in `@media print` rules for clean, standard browser-to-PDF exporting. (内置打印样式，支持通过浏览器完美导出为标准 PDF。)
- **🎨 Glassmorphism Style (微光玻璃拟态):** Premium dark radial gradients, glowing card panels, and crisp layouts. (高级暗黑径向渐变背景、流光玻璃拟态卡片面板。)
